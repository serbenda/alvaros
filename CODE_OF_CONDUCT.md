# Code of conduct

This is a friendly project for a neighbourhood bar. Everyone who takes part — opening issues, suggesting ideas or sending code — is expected to:

- Be kind and respectful, and assume good intentions.
- Welcome people of every age, background and level of experience.
- Give and accept constructive feedback about the work, never about the person.
- Keep jokes about the bar and the team affectionate: they are real people.

Harassment, insults, discrimination or sharing other people's private information are not accepted. Maintainers may remove comments, issues or contributions that break these rules and block people who repeatedly do so.

To report a problem, contact the maintainer privately through GitHub ([@serbenda](https://github.com/serbenda)).

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org/).
