# Security policy

The game is a static website with no server, no accounts and no personal data: progress is stored only in the player's own browser.

If you find a security problem anyway (for example, something that could run unwanted code in the page), please do not open a public issue. Report it privately through GitHub's **Report a vulnerability** option in the Security tab of this repository, or contact [@serbenda](https://github.com/serbenda). You will get an answer as soon as possible.
